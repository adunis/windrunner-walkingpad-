## Downloads

- **WalkingPad.exe**: the Windows app (build 20261116-1016). Just run it. If SmartScreen warns, choose *More info → Run anyway*.
- **Windrunner.zip**: the WoW addon. Unzip it into `World of Warcraft\_retail_\Interface\AddOns` (or `_classic_era_` and so on), so you get `AddOns\Windrunner\Windrunner.toc`.

## New in Windrunner 3.3

- **Sessions window**: open it with the Sessions button or `/wr sessions`.
  - Every session, with its time and distance.
  - Your character's route drawn on each zone map.
  - **Places**: how far you walked in each zone, dungeon, raid, battleground or delve.
  - **All sessions** adds everything up.
- **Off mode** (from 3.2) and a **Manual / App / Off** switch right in the window.
